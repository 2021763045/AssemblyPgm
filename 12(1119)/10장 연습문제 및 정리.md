# 10.7 Review Questions and Exercises
## 10.7.1 Short Answer

### 1. `STRUCT` 지시어의 목적

서로 다른 자료형의 필드를 하나의 구조체 형식으로 묶어 정의한다. 이후 그 형식으로 구조체 변수를 선언할 수 있다.

### 2. 선언의 유효성

| 선언 | 유효성 | 설명 |
|---|---|---|
| `rentals RentalInvoice <>` | 유효 | 구조체 변수 이름 뒤에 형식 이름을 쓴다. |
| `RentalInvoice rentals <>` | 무효 | 구조체 형식 이름과 변수 이름의 순서가 바뀌었다. |
| `march RentalInvoice <'12345',10,0>` | 유효 | 필드 순서와 자료형이 맞는다. |
| `RentalInvoice <,10,0>` | 무효 | 변수 이름이 없다. |
| `current RentalInvoice <,15,0>` | 유효 | 첫 필드는 기본값을 사용하고 나머지 필드를 초기화한다. |

### 3. 매크로에 데이터 정의를 포함할 수 있는가?

**False.** 매크로 안에 데이터 정의를 포함할 수 있다.

### 4. `LOCAL` 지시어의 목적

매크로 내부에서 사용할 고유한 지역 레이블을 선언한다. 매크로가 여러 번 확장돼도 레이블 이름이 중복되지 않게 한다. 프로시저 안에서는 지역 변수 선언에도 사용된다.

### 5. 어셈블리 중 콘솔에 메시지를 출력하는 지시어

`ECHO`

### 6. 조건부 블록의 끝을 표시하는 지시어

`ENDIF`

### 7. 상수 불리언 식에서 사용할 수 있는 관계 연산자

| 연산자 | 의미 |
|---|---|
| `EQ` | 같음 |
| `NE` | 같지 않음 |
| `LT` | 작음 |
| `LE` | 작거나 같음 |
| `GT` | 큼 |
| `GE` | 크거나 같음 |

### 8. 매크로 정의에서 `&` 연산자의 목적

매크로 매개변수를 다른 텍스트에 붙여 쓸 때 매개변수의 경계를 분명히 하고, 매개변수 값을 문자열 등에 치환한다.

### 9. 매크로 정의에서 `!` 연산자의 목적

뒤에 오는 문자를 특수 연산자가 아닌 문자 그대로 처리하게 한다.

### 10. 매크로 정의에서 `%` 연산자의 목적

상수식을 계산하거나 텍스트 매크로를 확장해 텍스트로 치환한다.

### 4. `Triangle` 구조체 배열에서 `Vertex1`을 무작위 좌표로 초기화

`RandomRange`에 11을 전달하면 0부터 10까지의 값을 얻는다. 난수 생성 전에 `Randomize`를 한 번 호출한다.

```asm
.code

mov ecx, ARRAY_SIZE
mov esi, 0

L1:
    mov eax, 11
    call RandomRange
    mov triangles[esi].Vertex1.X, ax

    mov eax, 11
    call RandomRange
    mov triangles[esi].Vertex1.Y, ax

    add esi, TYPE Triangle
    loop L1
```

### 5. `mPrintChar` 매크로 작성하기

문자를 지정한 횟수만큼 출력한다. `LOCAL`로 반복 레이블을 만들어 매크로를 여러 번 호출해도 레이블이 겹치지 않게 한다.

```asm
mPrintChar MACRO char, count
    LOCAL printLoop, done

    push eax
    push ecx

    mov ecx, count
    jecxz done
    mov al, char

printLoop:
    call WriteChar
    loop printLoop

done:
    pop ecx
    pop eax
ENDM
```

호출 예:

```asm
mPrintChar 'X', 20
```

## 1. `mReadkey` 매크로

```asm
mReadkey MACRO asciiResult, scanResult
    call ReadChar
```

테스트 코드:

```asm

    mReadkey ascii, scan

    movzx eax, ascii

    call Crlf

    call WriteHex
```

```asm
    ELSEIF TYPE destination EQ 4
```


## 7. 교수의 잃어버린 휴대전화

걷기 시작 전에 휴대전화를 잃어버릴 걸음 수를 정하고, 해당 걸음에 도달하면 현재 위치를 출력한다. `currX`, `currY`, `walkFinished`는 기존 `DrunkardWalk` 프로그램의 좌표 변수와 종료 레이블에 맞춘다.

```asm
.data
dropAfter DWORD ?
stepCount DWORD 0

.code
; 걷기 시작 전
call Randomize
mov  eax, 100
call RandomRange
inc  eax                 ; 1~100 걸음
mov  dropAfter, eax

; 기존 걷기 루프에서 좌표를 갱신한 뒤 실행
inc  stepCount
mov  eax, stepCount
cmp  eax, dropAfter
jne  continueWalk

mWrite "Phone dropped at: X="
mov  eax, currX
call WriteInt

mWrite ", Y="
mov  eax, currY
call WriteInt
call Crlf

jmp walkFinished

continueWalk:
; 기존 걷기 루프의 나머지 부분
```

## 8. 확률을 적용한 Drunkard’s Walk

방향은 `0=N`, `1=E`, `2=S`, `3=W`로 표현한다.

- 50%: 현재 방향 유지
- 10%: 반대 방향으로 전환
- 20%: 오른쪽으로 전환
- 20%: 왼쪽으로 전환

```asm
.data
direction DWORD ?

.code
call Randomize

; 기본 시작 방향을 무작위로 설정: 0~3
mov eax, 4
call RandomRange
mov direction, eax

; 매 걸음마다 실행
mov eax, 10
call RandomRange             ; 0~9

cmp eax, 5
jb  keepDirection            ; 0~4: 50%

cmp eax, 6
jb  reverseDirection         ; 5: 10%

cmp eax, 8
jb  turnRight                ; 6~7: 20%

; 8~9: 왼쪽으로 90도 전환, 20%
add direction, 3
and direction, 3
jmp directionReady

reverseDirection:
add direction, 2
and direction, 3
jmp directionReady

turnRight:
inc direction
and direction, 3
jmp directionReady

keepDirection:
; 방향을 유지한다.

directionReady:
; direction 값에 따라 이동
; 0 = 북쪽, 1 = 동쪽, 2 = 남쪽, 3 = 서쪽
```

## 9. 여러 DWORD 배열을 비트 이동하기

이 매크로는 little-endian DWORD 배열 전체를 이동한다. 이동 수는 `0~31`로 제한한다.

```asm
mShiftDoublewords MACRO arrayName, direction, numberOfBits
    LOCAL rightLoop, leftLoop, shiftDone

    pushad

    mov edx, numberOfBits
    and edx, 1Fh                 ; 0~31로 제한

    IFIDNI <direction>, <R>

        ; 오른쪽 이동: 높은 DWORD부터 낮은 DWORD 방향으로 처리
        mov edi, LENGTHOF arrayName
        cmp edi, 1
        jbe shiftDone

        dec edi                  ; 마지막 원소 인덱스
        mov esi, edi
        dec esi

rightLoop:
        mov eax, DWORD PTR arrayName[esi*4]
        mov ecx, edx
        shrd DWORD PTR arrayName[edi*4], eax, cl

        dec edi
        dec esi
        cmp edi, 0
        jne rightLoop

        mov ecx, edx
        shr DWORD PTR arrayName[0], cl

    ELSE

        ; 왼쪽 이동: 낮은 DWORD부터 높은 DWORD 방향으로 처리
        mov edi, 0
        mov esi, 1
        mov ebx, LENGTHOF arrayName
        dec ebx                  ; DWORD 사이 이동 횟수
        jz shiftDone

leftLoop:
        mov eax, DWORD PTR arrayName[esi*4]
        mov ecx, edx
        shld DWORD PTR arrayName[edi*4], eax, cl

        inc edi
        inc esi
        dec ebx
        jnz leftLoop

        mov ecx, edx
        shl DWORD PTR arrayName[edi*4], cl

    ENDIF

shiftDone:
    popad
ENDM
```

테스트 코드:

```asm
INCLUDE Irvine32.inc
INCLUDE Macros.inc

.data
rightArray DWORD 12345678h, 9ABCDEF0h, 11223344h
leftArray  DWORD 12345678h, 9ABCDEF0h, 11223344h

.code
main PROC
    mShiftDoublewords rightArray, R, 4
    mShiftDoublewords leftArray, L, 4

    mWrite "Right shift:"
    call Crlf
    mDumpMem OFFSET rightArray, LENGTHOF rightArray, TYPE rightArray

    mWrite "Left shift:"
    call Crlf
    mDumpMem OFFSET leftArray, LENGTHOF leftArray, TYPE leftArray

    exit
main ENDP
END main
```

## 10. 세 개의 피연산자를 사용하는 산술 매크로

모든 피연산자는 부호 있는 DWORD 메모리 변수다. `EAX`는 임시 레지스터로 사용하며 보존하지 않는다. 나눗셈에서 변경되는 `EDX`는 보존한다.

```asm
mAdd3 MACRO destination, source1, source2
    mov eax, source1
    add eax, source2
    mov destination, eax
ENDM

mSub3 MACRO destination, source1, source2
    mov eax, source1
    sub eax, source2
    mov destination, eax
ENDM

mMul3 MACRO destination, source1, source2
    mov eax, source1
    imul eax, source2
    mov destination, eax
ENDM

mDiv3 MACRO destination, source1, source2
    push edx
    mov  eax, source1
    cdq
    idiv source2
    mov  destination, eax
    pop  edx
ENDM
```

테스트 코드:

```asm
INCLUDE Irvine32.inc

.data
a       SDWORD 30
b       SDWORD 6
c       SDWORD 3
temp    SDWORD ?
result1 SDWORD ?
result2 SDWORD ?
result3 SDWORD ?
result4 SDWORD ?

.code
main PROC
    ; result1 = (a + b) * c = 108
    mAdd3 temp, a, b
    mMul3 result1, temp, c

    ; result2 = (a - b) / c = 8
    mSub3 temp, a, b
    mDiv3 result2, temp, c

    ; result3 = (a * b) + c = 183
    mMul3 temp, a, b
    mAdd3 result3, temp, c

    ; result4 = (a / b) - c = 2
    mDiv3 temp, a, b
    mSub3 result4, temp, c

    mov eax, result1
    call WriteInt
    call Crlf

    mov eax, result2
    call WriteInt
    call Crlf

    mov eax, result3
    call WriteInt
    call Crlf

    mov eax, result4
    call WriteInt
    call Crlf

    exit
main ENDP
END main
```

`mDiv3` 테스트에서는 제수가 0이 아니어야 하며, `INT_MIN / -1`처럼 32비트 결과가 넘치는 입력은 피한다.

# 10. Structures and Macros

## 1. 구조체와 공용체

구조체는 관련된 여러 필드를 하나의 형식으로 묶는다. 필드마다 자료형이 달라도 되고, 구조체 변수 전체 또는 개별 필드에 접근할 수 있다. 구조체는 `STRUCT`와 `ENDS`로 정의한다. 

```asm
Point STRUCT
    X SDWORD ?
    Y SDWORD ?
Point ENDS

.data
origin Point <0, 0>
target Point <10, 20>

.code
mov eax, target.X
```

- `?`는 필드의 초기값을 지정하지 않는다.
- 구조체 변수는 꺾쇠괄호로 초기화한다. `< >`를 쓰면 구조체 정의의 기본 필드 값을 사용한다.
- 일부 필드만 초기화할 수도 있다.
- `TYPE`, `SIZEOF`, `OFFSET`으로 구조체의 크기와 필드의 위치를 확인할 수 있다. 
- 공용체(Union)는 여러 필드가 같은 메모리 영역을 공유한다. 초기화 값은 하나만 지정하며, 사용할 때는 필드 이름을 명시한다. 

## 2. 매크로

매크로는 이름이 있는 어셈블리 문장 묶음이다. 매크로를 호출하면 전처리 단계에서 매크로 본문이 호출 위치에 삽입된다. 매개변수는 값, 변수 이름, 레지스터 이름 등을 전달하는 텍스트 자리표시자다. 

```asm
mWriteInt MACRO value
    mov eax, value
    call WriteInt
ENDM

; 호출
mWriteInt number
```

매크로 안의 레이블이 여러 번 확장되며 이름 충돌을 일으키지 않도록 `LOCAL`로 고유 레이블을 선언한다. 매크로 안에서 다른 매크로를 호출하는 것도 가능하다. 

Irvine 매크로 라이브러리에는 라이브러리 프로시저를 간편하게 호출하는 래퍼 매크로가 포함된다. 예를 들어 `mGotoxy`, `mWrite`, `mWriteString`, `mReadString`, `mDumpMem` 등을 사용할 수 있다. 

## 3. 조건부 어셈블리

조건부 어셈블리 지시어는 어셈블 시점에 조건을 검사해 생성할 코드를 선택한다. 실행 중에 분기하는 `IF` 명령어와 달리, 조건을 만족하지 않는 코드 블록은 출력 코드에 포함되지 않는다.

| 지시어 | 기능 |
|---|---|
| `IF`, `ELSE`, `ENDIF` | 조건에 따라 생성할 코드 선택 |
| `IFB`, `IFNB` | 매크로 인수가 비어 있는지 검사 |
| `IFDEF`, `IFNDEF` | 심볼이 정의되었는지 검사 |
| `IFIDN`, `IFIDNI` | 두 텍스트가 같은지 비교 |
| `ECHO` | 어셈블 중 메시지 출력 |
| `EXITM` | 매크로 확장 종료 |

상수 비교에는 `EQ`, `NE`, `LT`, `LE`, `GT`, `GE` 같은 관계 연산자를 사용할 수 있다. 조건부 어셈블리는 인수의 유효성 검사나 자료형에 따른 코드 선택에 활용된다. 

## 4. 매크로 특수 연산자

| 연산자 | 기능 |
|---|---|
| `&` | 매크로 매개변수를 주변 텍스트에 치환하거나 연결 |
| `!` | 특수 문자를 일반 문자로 처리 |
| `%` | 텍스트 매크로를 확장하거나 상수식을 텍스트로 변환 |
| `< >` | 여러 문자나 텍스트를 하나의 인수로 묶음 |

`%`를 소스 코드 줄의 첫 문자로 사용하면 해당 줄의 텍스트 매크로와 매크로 함수가 확장된다. 

## 5. 반복 블록

MASM은 어셈블 시점에 코드 블록을 반복 생성하는 지시어를 제공한다. 

| 지시어 | 반복 방식 |
|---|---|
| `WHILE` | 상수식이 참인 동안 반복 |
| `REPEAT` | 지정한 횟수만큼 반복 |
| `FOR` | 쉼표로 구분된 심볼 목록을 순회 |
| `FORC` | 문자열의 각 문자를 순회 |

`REPEAT`는 고정 횟수의 반복 코드 생성에, `FOR`와 `FORC`는 목록이나 문자열에 따라 서로 다른 코드를 생성할 때 유용하다. 

## 핵심 정리

- 구조체는 서로 다른 자료형의 필드를 하나의 형식으로 묶는다.
- 공용체는 여러 필드가 메모리를 공유한다.
- 매크로는 호출 위치에 코드가 삽입되며, 매개변수는 텍스트로 치환된다.
- `LOCAL`은 매크로를 여러 번 호출할 때 레이블 이름이 충돌하는 것을 방지한다.
- 조건부 어셈블리와 반복 지시어를 이용하면 어셈블 시점에 코드를 선택하거나 반복 생성할 수 있다.
