# 7.9 Review Questions and Exercises
## 7.9.1 Short Answer

## 1. AL 값

| 항목 | 결과 |
|---|---:|
| a | `6Ah` |
| b | `EAh` |
| c | `FDh` |
| d | `A9h` |

## 2. AL 값

| 항목 | 결과 |
|---|---:|
| a | `9Ah` |
| b | `6Ah` |
| c | `A9h` |
| d | `3Ah` |

## 3. AX와 DX

`222h × 100h = 22200h`

- `AX = 2200h`
- `DX = 0022h`

## 4. AX 값

`63h ÷ 10h`의 몫은 `6`, 나머지는 `3`이다.

- `AX = 0306h`

## 5. EAX와 EDX

`123400h ÷ 10h = 12340h`

- `EAX = 00012340h`
- `EDX = 00000000h`

## 6. AX와 DX

`DX:AX = 05004000h`를 `10h`로 나누면 몫이 16비트를 초과한다. 따라서 나눗셈 오버플로 예외(`#DE`)가 발생한다.

## 7. BX 값

`ADC`는 두 값과 CF를 더한다.

- `BX = 5 + 60h + 1 = 66h`

## 8. 실행 결과

`RDX = 108h`가 제수 `100h`보다 크므로 몫이 64비트에 들어가지 않는다. 나눗셈 오버플로 예외(`#DE`)가 발생한다.

## 9. 수정 코드

결과를 `result`에 저장하고, 낮은 자리부터 바이트 단위로 처리한다.

```asm
.data
val1   QWORD 20403004362047A1h
val2   QWORD 055210304A2630B2h
result QWORD 0

.code
    mov ecx, 8
    mov esi, OFFSET val1
    mov edi, OFFSET val2
    mov ebx, OFFSET result
    clc

top:
    mov al, BYTE PTR [esi]
    sbb al, BYTE PTR [edi]
    mov BYTE PTR [ebx], al

    inc esi
    inc edi
    inc ebx
    loop top
```

- `result = 1AEE1FD3EBFA16EFh`

## 10. RAX 값

문제에 나온 `mov rax,multiplicand, 4`는 유효한 `MOV` 구문이 아니다. QWORD 값을 읽는 의도라면 다음처럼 작성한다.

```asm
mov rax, QWORD PTR [multiplicand]
```

- `RAX = 000102030405000h`

```asm

mov val1, ax
```

`val1 = -15 = FFF1h`

## 10. -276을 10으로 나누어 16비트 변수에 저장

```asm
mov ax, -276
cwd
mov bx, 10

mov val1, ax
```

`val1 = -27 = FFE5h`이고 나머지는 `-6`이다.

## 11. 32비트 부호 없는 연산

`val1 = (val2 * val3) / (val4 - 3)`

```asm
mov eax, val2
mul val3
mov ebx, val4
sub ebx, 3
div ebx
mov val1, eax
```

몫이 32비트 안에 들어가고, 분모가 0이 아니라고 가정한다.

## 12. 32비트 부호 있는 연산

`val1 = (val2 / val3) * (val1 + val2)`

```asm
mov eax, val2
cdq
idiv val3
mov ecx, eax

mov eax, val1
add eax, val2
imul eax, ecx
mov val1, eax
```

## 13. AL의 값을 십진수로 출력

입력 범위는 0~99이다. 십의 자리가 0이면 출력하지 않는다.

```asm
showDecimal18 PROC
    mov ah, 0
    mov bl, 10
    div bl
    push ax

    add al, '0'
    cmp al, '0'
    je  ones
    call WriteChar

ones:
    pop ax
    mov al, ah
    add al, '0'
    call WriteChar
    ret
showDecimal18 ENDP
```

## 14. `AAA` 실행 결과

`AX = 0072h`이고 `AF = 1`이다. `AAA`는 조정 후 `AX = 0108h`를 만든다. 두 십진수로 보면 `18`에 해당한다. 실행 후 `AF`와 `CF`는 1이다.

## 15. `n mod y` 계산

`y`가 2의 거듭제곱이면 `n mod y = n AND (y - 1)`이다.

```asm
mov eax, n
mov ebx, y
sub ebx, 1
and eax, ebx
mov x, eax
```

## 16. EAX의 절댓값 계산

```asm
mov edx, eax
sar edx, 31
add eax, edx
xor eax, edx
```

단, `EAX = 80000000h`인 경우 결과도 `80000000h`로 남는다. 이는 32비트 signed 정수에서 절댓값을 표현할 수 없는 값이다.

# 7.10 Programming Exercises

## 1. WriteScaled

`EDX`는 문자열 주소, `ECX`는 길이, `EBX`는 소수점 위치다. `EBX`는 문자열 길이보다 작거나 같다고 가정한다.

```asm
WriteScaled PROC
    pushad
    mov esi, edx
    mov edi, ecx
    mov ebp, ecx
    sub ebp, ebx          ; 소수점 앞 문자 수
    xor ecx, ecx

L1:
    cmp ecx, edi
    jae Done1

    cmp ebx, 0
    je  PrintChar
    cmp ecx, ebp
    jne PrintChar

    mov al, '.'
    call WriteChar

PrintChar:
    mov al, [esi+ecx]
    call WriteChar
    inc ecx
    jmp L1

Done1:
    popad
    ret
WriteScaled ENDP
```

예시 문자열 `"100123456789765"`에 `EBX = 5`를 전달하면 `1001234567.89765`가 출력된다.

## 2. Extended_Sub

두 수와 결과는 최하위 바이트부터 메모리에 저장한다고 가정한다. `EDX`는 결과 주소, `ECX`는 바이트 수다.

```asm
Extended_Sub PROC
    clc
L2:
    mov al, [esi]
    sbb al, [edi]
    mov [edx], al

    inc esi
    inc edi
    inc edx
    loop L2
    ret
Extended_Sub ENDP
```

테스트 호출 예시. 배열마다 10바이트를 사용한다.

```asm
.data
numA BYTE 10h, 20h, 30h, 40h, 50h, 60h, 70h, 80h, 90h, 10h
numB BYTE 01h, 02h, 03h, 04h, 05h, 06h, 07h, 08h, 09h, 00h
result BYTE 10 DUP(?)

.code
mov esi, OFFSET numA
mov edi, OFFSET numB
mov edx, OFFSET result
mov ecx, LENGTHOF numA
call Extended_Sub
```

## 3. PackedToAsc

4바이트 packed BCD를 8자리 ASCII 문자열로 변환한다. 출력은 선행 0을 포함한다.

```asm
PackedToAsc PROC
    pushad
    add esi, 3
    mov ecx, 4

L3:
    mov al, [esi]
    mov ah, al

    shr al, 4
    and al, 0Fh
    add al, '0'
    stosb

    mov al, ah
    and al, 0Fh
    add al, '0'
    stosb

    dec esi
    loop L3

    mov BYTE PTR [edi], 0
    popad
    ret
PackedToAsc ENDP
```

호출 시 `ESI`에 packed 정수 주소, `EDI`에 9바이트 이상인 출력 버퍼 주소를 넣는다. 예를 들어 `DWORD 12345678h`는 `"12345678"`로 변환된다.

## 4. Encryption Using Rotate Operations

`ESI`는 메시지, `EDI`는 10바이트 키, `ECX`는 메시지 길이다. 메시지를 제자리에서 암호화한다.

```asm
Encrypt PROC USES ebx ecx edx esi edi ebp
    mov ebp, ecx
    xor ebx, ebx

L4:
    mov al, [esi]
    movsx edx, BYTE PTR [edi+ebx]

    test edx, edx
    jz  StoreByte

    mov cl, dl
    jg  RotateRight

    neg cl
    rol al, cl
    jmp StoreByte

RotateRight:
    ror al, cl

StoreByte:
    mov [esi], al
    inc esi
    inc ebx
    cmp ebx, 10
    jb  NextByte
    xor ebx, ebx

NextByte:
    dec ebp
    jnz L4
    ret
Encrypt ENDP
```

호출할 때마다 다른 메시지와 키 주소를 전달하면 된다.

```asm
mov esi, OFFSET message1
mov edi, OFFSET key1
mov ecx, LENGTHOF message1
call Encrypt

mov esi, OFFSET message2
mov edi, OFFSET key2
mov ecx, LENGTHOF message2
call Encrypt
```

## 5. Prime Numbers

체 배열에서 합성수를 지운 뒤 남은 수를 출력한다.

```asm
.data
sieve BYTE 1001 DUP(1)

.code
mov BYTE PTR [sieve],   0
mov BYTE PTR [sieve+1], 0
mov ebx, 2

SieveLoop:
    mov eax, ebx
    imul eax, ebx
    cmp eax, 1000
    ja  PrintPrimes

    cmp BYTE PTR [sieve+ebx], 0
    je  NextPrime

    mov esi, eax

MarkLoop:
    cmp esi, 1000
    ja  NextPrime
    mov BYTE PTR [sieve+esi], 0
    add esi, ebx
    jmp MarkLoop

NextPrime:
    inc ebx
    jmp SieveLoop

PrintPrimes:
    mov edi, 2

PrintLoop:
    cmp edi, 1000
    ja  Done5
    cmp BYTE PTR [sieve+edi], 0
    je  SkipPrint

    mov eax, edi
    call WriteDec
    mov al, ' '
    call WriteChar

SkipPrint:
    inc edi
    jmp PrintLoop

Done5:
```

## 6. Greatest Common Divisor

`GCD(x, y)`를 스택 인자로 받으며 결과를 `EAX`로 반환한다. `INT_MIN`도 절댓값의 비트 패턴을 unsigned 값으로 처리한다.

```asm
GCD PROC
    push ebp
    mov ebp, esp
    push ebx
    push edx

    mov eax, [ebp+8]
    test eax, eax
    jns XReady
    neg eax

XReady:
    mov ebx, [ebp+12]
    test ebx, ebx
    jns YReady
    neg ebx

YReady:
    test ebx, ebx
    jz  GcdDone

GcdLoop:
    xor edx, edx
    div ebx
    mov eax, ebx
    mov ebx, edx
    test ebx, ebx
    jnz GcdLoop

GcdDone:
    pop edx
    pop ebx
    pop ebp
    ret 8
GCD ENDP
```

호출 예시:

```asm
push 18
push 48
call GCD
call WriteDec          ; 6 출력
```

## 7. BitwiseMultiply

`EAX`와 `EBX`를 곱하고 결과를 `EAX`에 반환한다. 곱이 32비트 범위 안에 들어간다고 가정한다.

```asm
BitwiseMultiply PROC
    push ebx
    push ecx
    push edx
    push esi
    push edi

    mov esi, eax        ; multiplier
    mov edi, ebx        ; multiplicand
    xor edx, edx        ; product
    mov ecx, 32

MultiplyLoop:
    shr esi, 1
    jnc SkipAdd
    add edx, edi

SkipAdd:
    shl edi, 1
    loop MultiplyLoop

    mov eax, edx
    pop edi
    pop esi
    pop edx
    pop ecx
    pop ebx
    ret
BitwiseMultiply ENDP
```

호출 예시:

```asm
mov eax, 12345
mov ebx, 6789
call BitwiseMultiply
call WriteDec
```

## 8. AddPacked

두 packed BCD 수와 결과는 최하위 바이트부터 저장한다. `ECX`는 입력 바이트 수이며, 결과 버퍼는 마지막 자리 올림을 위해 `ECX + 1`바이트가 필요하다.

```asm
AddPacked PROC
    pushad
    clc

L8:
    mov al, [esi]
    adc al, [edi]
    daa
    mov [edx], al

    inc esi
    inc edi
    inc edx
    loop L8

    mov BYTE PTR [edx], 0
    adc BYTE PTR [edx], 0

    popad
    ret
AddPacked ENDP
```

4바이트 테스트 예시:

```asm
.data
numA4 BYTE 78h, 56h, 34h, 12h
numB4 BYTE 22h, 22h, 22h, 00h
sum4  BYTE 5 DUP(?)

.code
mov esi, OFFSET numA4
mov edi, OFFSET numB4
mov edx, OFFSET sum4
mov ecx, 4
call AddPacked
```

계산 결과는 `14,567,900`이며 `sum4`에는 `00h, 79h, 56h, 14h, 00h`가 저장된다. 같은 방식으로 입력과 결과 버퍼를 8바이트, 16바이트로 준비해 호출하면 된다.
