# 7. Integer Arithmetic

## 개요

이 장에서는 x86 어셈블리의 정수 산술 명령어와 이를 이용한 비트 연산, 다중 정밀도 계산, 10진수 데이터 처리를 다룬다. 특히 레지스터 하나에 들어가지 않는 큰 수를 여러 단위로 나누어 계산하거나, 정수 값을 문자열로 변환하는 방법을 살펴본다.

## 1. 산술 명령어와 Carry

기본 산술 명령어는 `ADD`, `SUB`, `INC`, `DEC`, `NEG`, `CMP` 등이 있다. 연산 결과와 함께 상태 플래그가 바뀌며, 다중 정밀도 연산에서는 Carry Flag(CF)를 다음 단계로 전달해야 한다.

| 명령어 | 연산 |
|---|---|
| `ADC` | 목적지 + 원본 + CF |
| `SBB` | 목적지 - 원본 - CF |

예를 들어 64비트 값을 두 개의 32비트 레지스터로 나누어 더할 때는 낮은 32비트를 먼저 더하고, 그 자리에서 발생한 Carry를 높은 자리 연산에 반영한다.

```asm
add eax, low_part
adc edx, high_part
```

뺄셈은 낮은 자리에서 `SUB`, 높은 자리에서 `SBB`를 사용한다. `ADC`와 `SBB`는 각각 Carry와 Borrow를 전달하기 때문에 여러 바이트 또는 워드로 된 수를 계산할 때 유용하다. 

## 2. Shift와 Rotate

Shift 명령은 비트를 지정한 방향으로 이동한다. Rotate 명령은 이동 과정에서 밀려난 비트를 반대편에 다시 넣으므로 비트가 사라지지 않는다.

| 명령어 | 기능 |
|---|---|
| `SHL` / `SAL` | 왼쪽으로 이동하고 오른쪽 빈 자리를 0으로 채움 |
| `SHR` | 논리적 오른쪽 이동, 왼쪽 빈 자리를 0으로 채움 |
| `SAR` | 산술적 오른쪽 이동, 부호 비트를 유지 |
| `ROL` / `ROR` | 비트를 원형으로 왼쪽 또는 오른쪽 회전 |
| `RCL` / `RCR` | Carry Flag를 회전 경로에 포함 |
| `SHLD` / `SHRD` | 다른 피연산자의 비트로 빈 자리를 채우며 이동 |

`SHL`과 `SHR`은 정수를 2의 거듭제곱만큼 곱하거나 나누는 데 활용할 수 있다. 반면 음수를 산술적으로 오른쪽 이동할 때는 부호를 보존하는 `SAR`을 사용한다. `SHLD`와 `SHRD`는 여러 레지스터에 걸친 값의 비트를 이동할 때 사용한다. 

Shift 명령은 비트열을 문자 `'0'`, `'1'`로 변환하는 데도 쓸 수 있다. 예를 들어 레지스터의 최상위 비트를 Carry Flag로 이동시키고, CF 값에 따라 출력 문자를 선택하는 방식이다. 

## 3. 곱셈과 나눗셈

### 곱셈

- `MUL`은 부호 없는 정수 곱셈에 사용한다.
- `IMUL`은 부호 있는 정수 곱셈에 사용한다.
- 1피연산자 형식은 입력 크기에 따라 곱을 더 큰 레지스터 쌍에 저장한다.
- 2피연산자·3피연산자 `IMUL`은 결과를 목적지 크기에 맞춰 저장하므로, 결과 일부가 잘릴 수 있다. 이때는 Overflow Flag와 Carry Flag를 확인해야 한다. 

### 나눗셈

`DIV`는 부호 없는 나눗셈, `IDIV`는 부호 있는 나눗셈에 사용한다. 나눗셈 결과는 몫과 나머지로 나뉘어 정해진 레지스터에 저장된다.

| 연산 크기 | 피제수 | 몫 | 나머지 |
|---|---|---|---|
| 8비트 | `AX` | `AL` | `AH` |
| 16비트 | `DX:AX` | `AX` | `DX` |
| 32비트 | `EDX:EAX` | `EAX` | `EDX` |

`IDIV` 전에 피제수는 부호에 맞게 확장해야 한다. 예를 들어 `CWD`는 `AX`의 부호를 `DX`로 확장한다. 제수가 0이거나 몫이 저장할 레지스터 크기를 넘으면 나눗셈 예외가 발생한다. `DIV`와 `IDIV` 실행 후 산술 플래그 값은 정의되지 않는다. 

## 4. ASCII와 Unpacked Decimal

ASCII 숫자는 문자 코드로 저장되고, unpacked decimal은 숫자 하나를 한 바이트에 저장한다. Unpacked decimal의 상위 4비트는 0인 반면, ASCII 숫자는 상위 비트가 `0011`이다. 

`AAA`, `AAS`, `AAM`, `AAD`는 unpacked decimal 연산 결과를 조정하는 명령어다.

- `AAA`: 덧셈 결과 조정
- `AAS`: 뺄셈 결과 조정
- `AAM`: 곱셈 결과를 unpacked decimal로 조정
- `AAD`: 나눗셈 전 unpacked decimal 피제수 조정

ASCII 숫자 문자열에 고정 소수점을 표시할 때는 실제 소수점 문자를 저장하지 않고, 문자열 오른쪽에서 몇 자리 앞에 소수점을 출력할지 별도로 정할 수 있다. 문자열 덧셈 예제에서는 오른쪽 끝부터 각 자릿수를 처리하고, 올림을 다음 자리로 전달한다. 

## 5. Packed Decimal

Packed decimal은 한 바이트에 10진수 숫자 두 자리를 저장한다. 각 4비트가 숫자 한 자리에 해당한다.

`DAA`는 `ADD` 또는 `ADC`로 계산한 `AL` 값을 packed decimal 형식에 맞게 조정한다. 여러 바이트 값을 더할 때는 낮은 바이트부터 `ADD`/`ADC`와 `DAA`를 반복하고, 마지막 Carry도 결과에 저장해야 한다. 

## 6. 이 장의 주요 응용 문제

이 장의 실습에서는 산술 명령어를 조합해 다음과 같은 프로그램을 구현한다.

- 고정 소수점이 있는 숫자 문자열 출력
- 임의 크기 정수의 덧셈과 뺄셈
- Packed decimal과 ASCII 문자열 간 변환
- Rotate 명령을 이용한 간단한 암호화
- 에라토스테네스의 체를 이용한 소수 생성
- 유클리드 알고리즘을 이용한 최대공약수 계산
- Shift와 덧셈을 이용한 곱셈
- 여러 바이트 길이의 packed decimal 덧셈

## 핵심 정리

- 여러 바이트로 된 정수는 낮은 자리부터 처리하고 CF를 다음 자리로 전달한다.
- 산술 Shift와 논리 Shift는 부호 비트 처리 방식이 다르다.
- `MUL`/`IMUL`과 `DIV`/`IDIV`는 부호 유무에 맞게 선택한다.
- 곱셈에서는 결과가 목적지 크기에 들어가는지 확인한다.
- 나눗셈 전에는 피제수 확장, 제수 0 여부, 몫의 크기를 점검한다.
- ASCII, unpacked decimal, packed decimal은 저장 형식에 맞는 조정 명령어를 사용한다.
