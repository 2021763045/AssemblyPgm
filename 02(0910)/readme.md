# 2장 x86 Processor Architecture 정리

## 1. 개요

x86 프로세서 아키텍처는 인텔 계열 CPU에서 사용되는 구조이다. 이 장에서는 32비트 x86과 64비트 x86-64 프로세서의 레지스터, 상태 플래그, 메모리, 입출력 시스템을 다룬다. 

---

## 2. 32비트 x86 프로세서

32비트 x86 프로세서는 주로 8개의 일반 목적 레지스터를 사용한다.

| 레지스터 | 주요 용도 |
|---|---|
| `EAX` | 산술 연산, 함수 반환값 |
| `EBX` | 데이터 저장 |
| `ECX` | 반복문 카운터 |
| `EDX` | 입출력, 곱셈·나눗셈 연산 |
| `ESI` | 문자열/배열의 원본 위치 |
| `EDI` | 문자열/배열의 목적지 위치 |
| `EBP` | 스택 프레임 기준 위치 |
| `ESP` | 스택의 현재 위치 |

- `ESP`는 스택의 가장 위 위치를 가리킨다.
- `EBP`는 지역 변수와 함수 매개변수에 접근할 때 기준 주소로 사용된다.
- x86 프로세서는 산술, 논리, 메모리 접근, 분기 등의 명령어를 수행한다. 

---

## 3. CPU 상태 플래그

CPU는 연산 결과에 대한 정보를 상태 플래그에 저장한다.

| 플래그 | 의미 |
|---|---|
| `CF` | 부호 없는 연산에서 자리올림 또는 범위 초과 발생 |
| `ZF` | 연산 결과가 0 |
| `SF` | 연산 결과가 음수 |
| `OF` | 부호 있는 연산에서 오버플로 발생 |
| `PF` | 결과의 하위 바이트에 1의 개수가 짝수 |
| `AF` | 하위 4비트에서 자리올림 발생 |

특히 `CF`는 **unsigned 연산**, `OF`는 **signed 연산**의 범위 초과를 판단할 때 사용한다.

---

## 4. 부동소수점 연산

부동소수점 연산은 **FPU(Floating-Point Unit)** 가 담당한다.

- x87 FPU는 최대 8개의 부동소수점 레지스터를 제공한다.
- 각 x87 부동소수점 데이터 레지스터는 **80비트** 크기이다.
- 실수 연산, 삼각함수, 제곱근 등의 연산에 사용된다.

---

## 5. 64비트 x86-64 프로세서

x86-64는 기존 x86 구조를 확장한 64비트 아키텍처이다. 기존 x86 프로그램과의 하위 호환성을 제공한다. 

### 주요 특징

- 일반 목적 레지스터가 기존 8개에서 **16개**로 증가했다.
- 기존 레지스터는 64비트 크기로 확장되었다.
- 추가 레지스터로 `R8`~`R15`를 사용할 수 있다.
- 64비트 레지스터 이름은 `RAX`, `RBX`, `RCX`, `RDX`, `RSI`, `RDI`, `RBP`, `RSP` 등이다.
- REX prefix를 사용하면 확장 레지스터와 64비트 피연산자를 사용할 수 있다.
- 현재의 64비트 CPU는 주소 지정에 64비트를 전부 사용하지는 않는다.

| 32비트 레지스터 | 64비트 확장 레지스터 |
|---|---|
| `EAX` | `RAX` |
| `EBX` | `RBX` |
| `ECX` | `RCX` |
| `EDX` | `RDX` |
| `ESI` | `RSI` |
| `EDI` | `RDI` |
| `EBP` | `RBP` |
| `ESP` | `RSP` |

---

## 6. 메모리

컴퓨터는 목적에 따라 여러 종류의 메모리를 사용한다.

| 메모리 종류 | 특징 |
|---|---|
| RAM | 프로그램 실행 중 데이터를 임시 저장하는 휘발성 메모리 |
| DRAM | 주기적인 refresh가 필요한 RAM, 비교적 저렴함 |
| SRAM | refresh가 필요 없고 빠르지만 DRAM보다 비쌈 |
| CMOS RAM | 시스템 설정 정보를 저장하며, 배터리 전원으로 데이터를 유지함 |
| VRAM | 그래픽 화면 데이터를 저장하는 비디오 메모리 |
| EPROM | 자외선으로 내용을 지울 수 있는 ROM 종류 |

- DRAM은 주기적인 refresh가 필요하다.
- SRAM은 빠르지만 가격이 높아 주로 CPU 캐시에 사용된다.
- CMOS RAM은 전원이 필요하지만 DRAM처럼 refresh는 필요하지 않는다.

---

## 7. 컴퓨터 구성 요소

일반적인 x86 컴퓨터는 CPU, 메인 메모리, 저장 장치, 입출력 장치, 버스로 구성된다. 

| 구성 요소 | 역할 |
|---|---|
| CPU | 명령어를 해석하고 실행 |
| 메인 메모리 | 실행 중인 프로그램과 데이터를 저장 |
| 저장 장치 | 운영체제, 프로그램, 파일을 장기 저장 |
| 마더보드 | 모든 하드웨어 장치를 연결 |
| 버스 | CPU, 메모리, 주변 장치 간 데이터를 전달 |
| 확장 슬롯 | 그래픽 카드, 사운드 카드 등을 연결 |

---

## 8. 버스와 PCI

버스는 컴퓨터 내부 장치들이 데이터를 주고받는 통신 경로이다.

- 버스는 주소, 데이터, 제어 신호를 전달한다.
- PCI는 **Peripheral Component Interconnect**의 약자이다.
- PCI 슬롯에는 그래픽 카드, 사운드 카드, 네트워크 카드 등의 확장 카드를 연결할 수 있다.

---

## 9. 입출력 시스템

입출력 시스템은 키보드, 마우스, 모니터, 디스크, 네트워크 장치 등과 CPU가 통신하도록 한다. 

### I/O 접근 방법

| 수준 | 방법 |
|---|---|
| 응용 프로그램 수준 | 운영체제가 제공하는 I/O 함수 또는 시스템 호출 사용 |
| 시스템 수준 | 하드웨어 I/O 포트에 직접 접근 |

일반 응용 프로그램은 운영체제를 통해 장치를 사용한다. 반면 운영체제, 드라이버, 임베디드 프로그램 등은 하드웨어 포트를 직접 제어할 수 있다.

---

## 10. 인터럽트

인터럽트는 하드웨어 장치가 CPU에게 처리가 필요한 일이 발생했음을 알리는 신호이다.

- 키보드 입력, 마우스 이동, 타이머, 디스크 작업 완료 등이 인터럽트를 발생시킨다.
- CPU는 현재 작업을 잠시 멈추고 인터럽트 처리 루틴을 실행한다.
- **8259A PIC**는 외부 하드웨어 인터럽트를 관리하는 컨트롤러이다.

---

## 핵심 정리

- `EBP`는 스택 프레임의 기준 주소, `ESP`는 스택의 현재 위치를 가리킨다.
- `CF`는 unsigned 연산의 오버플로, `OF`는 signed 연산의 오버플로를 나타낸다.
- FPU는 부동소수점 연산을 수행하며 x87 레지스터는 80비트이다.
- x86-64는 x86과 하위 호환되며, 일반 목적 레지스터가 총 16개이다.
- SRAM은 빠르지만 비싸고, DRAM은 저렴하지만 refresh가 필요하다.
- PCI는 확장 카드를 연결하는 인터페이스이다.
- I/O는 운영체제를 통해 처리하거나 하드웨어 포트에 직접 접근할 수 있다.
