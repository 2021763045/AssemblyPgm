# 8.10 Review Questions and Exercises

## 8.10.1 Short Answer

1. **프로시저 에필로그:** 스택 프레임을 해제하고 저장했던 `EBP`를 복원한다. `stdcall`이면 파라미터 공간도 정리한다.
   ```asm
   mov esp, ebp
   pop ebp
   ret  파라미터바이트수
   ```

2. C 함수가 반환하는 32비트 정수는 **EAX**에 저장된다.

3. `stdcall`에서는 호출된 프로시저가 `ret n`으로 스택 파라미터를 정리한다.

4. `OFFSET`은 변수의 주소를 구한다. `LEA`는 베이스, 인덱스, 변위 등을 조합한 유효 주소를 계산할 수 있어 스택 파라미터나 배열 원소의 주소를 구할 때 더 유용하다.

5. C++의 `int` 변수는 **4바이트**를 사용한다.

6. C 호출 규약의 장점은 가변 개수 파라미터를 처리할 수 있다는 점이다. 호출한 쪽이 스택을 정리하기 때문이다.

7. **False.** MASM은 줄 연속 문법을 사용해 파라미터 목록을 여러 줄에 나눌 수 있다. ([learn.microsoft.com](https://learn.microsoft.com/ko-kr/cpp/assembler/masm/masm-bnf-grammar?view=msvc-170&utm_source=openai))

8. **False.** 주소를 DWORD 변수에 저장하면 배열 원소의 자료형 정보가 없어지므로, 잘못된 포인터 형식으로 전달해도 어셈블러가 오류를 잡지 못할 수 있다.

9. **True.** 참조 파라미터에 즉시값을 주소처럼 넘긴 뒤 역참조하면 잘못된 메모리 접근으로 일반 보호 예외가 발생할 수 있다.

### 1. AddThree 호출 직후 스택 프레임

호출 코드에서 `10h`, `20h`, `30h` 순으로 push했으므로, 첫 번째 파라미터가 가장 높은 주소에 놓인다.

```text
높은 주소
[EBP+16]  10h       ; 첫 번째로 push한 인자
[EBP+12]  20h
[EBP+08]  30h       ; 마지막으로 push한 인자
[EBP+04]  반환 주소
[EBP+00]  호출자의 EBP
낮은 주소
```

### 2. 세 정수의 합을 반환하는 AddThree

```asm
AddThree PROC, a:DWORD, b:DWORD, c:DWORD
    mov eax, a
    add eax, b
    add eax, c
    ret
AddThree ENDP
```

`stdcall`을 사용하면 반환 시 파라미터 공간도 정리된다.

### 8. SetColor

`SetTextColor`에 전달하는 값은 배경색을 상위 4비트, 글자색을 하위 4비트에 넣는다.

```asm
SetColor PROC, foreColor:DWORD, backColor:DWORD
    mov eax, backColor
    shl eax, 4
    or  eax, foreColor
    call SetTextColor
    ret
SetColor ENDP
```

### 9. WriteColorChar

문자 하나를 지정한 전경색과 배경색으로 출력한다.

```asm
WriteColorChar PROC, char:DWORD, foreColor:DWORD, backColor:DWORD
    INVOKE SetColor, foreColor, backColor
    mov al, BYTE PTR char
    call WriteChar
    ret
WriteColorChar ENDP
```

### 10. DumpMemory 래퍼

Irvine32의 `DumpMem`은 `ESI`에 시작 주소, `ECX`에 원소 수, `EBX`에 원소 크기를 받는다.

```asm
DumpMemory PROC, pArray:PTR BYTE, itemCount:DWORD, itemSize:DWORD

    mov ecx, itemCount
    mov ebx, itemSize

    ret
DumpMemory ENDP
```

호출 예시:

# 8.11 Programming Exercises

## 1. FindLargest

부호 있는 doubleword 배열에서 최댓값을 찾아 EAX로 반환한다. 배열 길이는 1 이상으로 가정한다.

```asm
FindLargest PROTO, pArray:PTR SDWORD, count:DWORD

FindLargest PROC USES esi ecx edx, pArray:PTR SDWORD, count:DWORD
    mov esi, pArray
    mov ecx, count
    mov eax, [esi]          ; 현재 최댓값
    add esi, 4
    dec ecx
    jz  FindDone

FindLoop:
    mov edx, [esi]
    cmp edx, eax
    jle NextItem
    mov eax, edx

NextItem:
    add esi, 4
    loop FindLoop

FindDone:
    ret
FindLargest ENDP
```

테스트 예시:

```asm
.data
arr1 SDWORD -5, -2, -9
arr2 SDWORD 12, 7, 21, 3
arr3 SDWORD -30, 0, -4, 18, -1

.code
INVOKE FindLargest, ADDR arr1, LENGTHOF arr1
call WriteInt
call Crlf

INVOKE FindLargest, ADDR arr2, LENGTHOF arr2
call WriteInt
call Crlf

INVOKE FindLargest, ADDR arr3, LENGTHOF arr3
call WriteInt
```

## 2–3. Chess Board와 색상 변경

아래 코드는 8×8 보드를 그린다. 흰 칸은 흰색으로 유지하고, 나머지 칸에는 `boardColor`를 적용한다. 한 칸을 공백 두 개로 그려 화면에서 정사각형에 가깝게 보이게 한다.

```asm
.data
boardRow   DWORD 0
boardCol   DWORD 0
boardColor DWORD 1

.code
DrawBoard PROC
    mov boardRow, 0

RowLoop:
    cmp boardRow, 8
    jae BoardDone

    mov dh, BYTE PTR boardRow
    mov dl, 0
    call Gotoxy
    mov boardCol, 0

ColLoop:
    cmp boardCol, 8
    jae NextRow

    mov eax, boardRow
    add eax, boardCol
    test eax, 1
    jnz WhiteSquare

    INVOKE WriteColorChar, ' ', 15, boardColor
    INVOKE WriteColorChar, ' ', 15, boardColor
    jmp NextCol

WhiteSquare:
    INVOKE WriteColorChar, ' ', 15, 15
    INVOKE WriteColorChar, ' ', 15, 15

NextCol:
    inc boardCol
    jmp ColLoop

NextRow:
    inc boardRow
    jmp RowLoop

BoardDone:
    ret
DrawBoard ENDP
```

500ms마다 색을 바꿔 16번 출력한다.

```asm
.data
colorIndex DWORD 0
rounds     DWORD 16

.code
ColorLoop:
    mov eax, colorIndex
    mov boardColor, eax
    call DrawBoard

    mov eax, 500
    call Delay

    inc colorIndex
    and colorIndex, 0Fh
    dec rounds
    jnz ColorLoop
```

## 4. FindThrees

배열에 값 `3`이 연속으로 세 번 나오면 EAX를 1로, 아니면 0으로 반환한다.

```asm
FindThrees PROTO, pArray:PTR SDWORD, count:DWORD

FindThrees PROC USES esi ecx, pArray:PTR SDWORD, count:DWORD
    xor eax, eax
    mov ecx, count
    cmp ecx, 3
    jb  FindThreesDone

    sub ecx, 2
    mov esi, pArray

CheckTriple:
    cmp DWORD PTR [esi], 3
    jne NextTriple
    cmp DWORD PTR [esi+4], 3
    jne NextTriple
    cmp DWORD PTR [esi+8], 3
    jne NextTriple

    mov eax, 1
    jmp FindThreesDone

NextTriple:
    add esi, 4
    loop CheckTriple

FindThreesDone:
    ret
FindThrees ENDP
```

## 5. DifferentInputs

세 값이 모두 다르면 1, 중복되는 값이 있으면 0을 반환한다.

```asm
DifferentInputs PROC USES edx, a:DWORD, b:DWORD, c:DWORD
    mov eax, a
    mov edx, b
    cmp eax, edx
    je  NotAllDifferent

    mov edx, c
    cmp eax, edx
    je  NotAllDifferent

    mov eax, b
    cmp eax, c
    je  NotAllDifferent

    mov eax, 1
    ret

NotAllDifferent:
    xor eax, eax
    ret
DifferentInputs ENDP
```

테스트에서는 서로 다른 인자 조합으로 다섯 번 호출하면 된다.

```asm
INVOKE DifferentInputs, 1, 2, 3
call WriteDec

INVOKE DifferentInputs, 4, 4, 5
call WriteDec
```

## 6. 연속된 정수 쌍 교환

`Swap`은 두 원소의 주소를 받는다고 가정한다.

```asm
Swap PROC USES eax edx ecx, p1:PTR DWORD, p2:PTR DWORD
    mov eax, p1
    mov edx, p2
    mov ecx, [eax]
    xchg ecx, [edx]
    mov [eax], ecx
    ret
Swap ENDP
```

배열을 두 원소씩 건너뛰며 교환한다.

```asm
mov esi, OFFSET intArray
mov ecx, LENGTHOF intArray / 2

SwapLoop:
    lea eax, [esi+4]
    push eax
    push esi
    call Swap

    add esi, 8
    loop SwapLoop
```

## 7. 재귀적 GCD

유클리드 알고리즘으로 최대공약수를 구한다. 입력값은 0 이상의 정수로 가정한다.

```asm
GCD PROC USES ebx edx, x:DWORD, y:DWORD
    mov eax, y
    test eax, eax
    jz  GCDBase

    mov eax, x
    xor edx, edx
    div DWORD PTR y
    INVOKE GCD, y, edx
    ret

GCDBase:
    mov eax, x
    ret
GCD ENDP
```

테스트할 쌍은 `(5,20)`, `(24,18)`, `(11,7)`, `(432,226)`, `(26,13)`이다.

## 8. CountMatches

두 배열에서 같은 위치의 값이 같은 원소 수를 반환한다.

```asm
CountMatches PROTO, pArray1:PTR SDWORD, pArray2:PTR SDWORD, count:DWORD

CountMatches PROC USES esi edi ecx edx, pArray1:PTR SDWORD, pArray2:PTR SDWORD, count:DWORD
    mov esi, pArray1
    mov edi, pArray2
    mov ecx, count
    xor eax, eax

MatchLoop:
    test ecx, ecx
    jz  MatchDone

    mov edx, [esi]
    cmp edx, [edi]
    jne NotMatch
    inc eax

NotMatch:
    add esi, 4
    add edi, 4
    dec ecx
    jmp MatchLoop

MatchDone:
    ret
CountMatches ENDP
```

## 9. CountNearMatches

두 배열에서 같은 위치의 값 차이가 `diff` 이하인 원소 수를 반환한다. 차이 계산은 부호 있는 값의 순서를 먼저 비교한 뒤 unsigned 차이로 확인한다.

```asm
CountNearMatches PROTO, pArray1:PTR SDWORD, pArray2:PTR SDWORD, count:DWORD, diff:DWORD

CountNearMatches PROC USES esi edi ecx edx ebx, pArray1:PTR SDWORD, pArray2:PTR SDWORD, count:DWORD, diff:DWORD
    mov esi, pArray1
    mov edi, pArray2
    mov ecx, count
    xor eax, eax

NearLoop:
    test ecx, ecx
    jz  NearDone

    mov ebx, [esi]
    mov edx, [edi]
    cmp ebx, edx
    jge FirstIsLarger

    sub edx, ebx
    cmp edx, diff
    jbe CountNear
    jmp NearNext

FirstIsLarger:
    sub ebx, edx
    cmp ebx, diff
    ja  NearNext

CountNear:
    inc eax

NearNext:
    add esi, 4
    add edi, 4
    dec ecx
    jmp NearLoop

NearDone:
    ret
CountNearMatches ENDP
```

## 10. ShowParams

`ShowParams`는 호출한 프로시저의 EBP 프레임을 따라가 파라미터 주소와 값을 낮은 주소부터 출력한다. 호출자도 표준 EBP 스택 프레임을 사용한다고 가정한다.

```asm
ShowParams PROC USES esi ecx, paramCount:DWORD
    mov ecx, paramCount

    mov esi, [ebp]       ; 호출자의 저장된 EBP
    add esi, 8            ; 호출자의 첫 번째 파라미터

ParamLoop:
    test ecx, ecx
    jz  ParamsDone

    push ecx

    mov edx, OFFSET addressText
    call WriteString
    mov eax, esi
    call WriteHex

    mov edx, OFFSET equalsText
    call WriteString
    mov eax, [esi]
    call WriteHex
    call Crlf

    pop ecx
    add esi, 4
    loop ParamLoop

ParamsDone:
    ret
ShowParams ENDP
```

호출 예시:

```asm
MySample PROC, first:DWORD, second:DWORD, third:DWORD
    INVOKE ShowParams, 3
    ret
MySample ENDP

INVOKE MySample, 1234h, 5000h, 6543h
```

`addressText`와 `equalsText`는 각각 `"Address "`와 `" = "`를 담은 널 종료 문자열로 선언하면 된다.
