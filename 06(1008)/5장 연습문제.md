# 5.8 Review Questions and Exercises
5.8.1 Short Answer

| 번호 | 정답 | 풀이 |
|---:|---|---|
| 1 | `PUSHAD` | 32비트 일반 목적 레지스터를 스택에 저장한다. |
| 2 | `PUSHFD` | `EFLAGS` 레지스터를 스택에 저장한다. |
| 3 | `POPFD` | 스택의 값을 `EFLAGS` 레지스터로 복원한다. |
| 4 | 필요한 레지스터만 선택해 저장할 수 있다. | `PUSH EAX`, `PUSH EBX`처럼 필요한 레지스터만 지정하면 `PUSHAD`보다 불필요한 저장을 줄이고 저장 대상을 명확히 할 수 있다. |
| 5 | `SUB ESP, 4` 후 `MOV [ESP], EAX` | 스택 포인터를 4바이트 내리고, 그 위치에 EAX 값을 저장하면 `PUSH EAX`와 같은 효과를 낸다. |
| 6 | **True** | `RET`은 스택에서 반환 주소를 꺼내 명령어 포인터로 이동한다. |
| 7 | **False** | 프로시저 안에서 다른 프로시저를 호출하는 중첩 호출은 가능하다. |
| 8 | **True** | 32비트 보호 모드의 near `CALL`은 반환 주소 4바이트를 스택에 저장한다. |
| 9 | **False** | `ESI`, `EDI`도 매개변수 전달에 사용할 수 있다. 어떤 레지스터를 쓸지는 호출 규약에 따른다. |
| 10 | **True** | `ArraySum`은 DWORD 배열의 주소를 전달받아 합을 계산하도록 작성할 수 있다. |
| 11 | **True** | `USES`에는 프로시저에서 변경하는 레지스터를 지정한다. |
| 12 | **False** | `USES`는 레지스터를 프로시저 시작 시 저장하고 종료 시 복원하는 코드를 생성한다. |
| 13 | **True** | `USES`의 레지스터 이름은 쉼표로 구분한다. 예: `USES eax, ecx, esi` |

## 14. `ArraySum`을 16비트 WORD 배열용으로 변경

WORD 배열의 각 요소는 2바이트이므로 포인터를 2씩 증가시킨다. unsigned WORD를 32비트 누산기에 더하기 위해 `MOVZX`를 사용한다.

```asm
; 입력:
;   ESI = WORD 배열의 주소
;   ECX = 배열 요소 개수
; 반환:
;   EAX = 요소의 합계

ArraySumWords PROC USES esi ecx edx
    mov eax, 0

L1:
    movzx edx, WORD PTR [esi]
    add eax, edx
    add esi, TYPE WORD
    loop L1

    ret
ArraySumWords ENDP
```

## 15. 명령어 실행 후 EAX 값

```asm
push 5
push 6
pop  eax
pop  eax
```

스택은 마지막에 넣은 값을 먼저 꺼내므로:

1. 첫 번째 `POP EAX` → `EAX = 6`
2. 두 번째 `POP EAX` → `EAX = 5`

**정답: `EAX = 5`**

## 16. 코드 실행 결과

```asm
main PROC
    push 10
    push 20
    call Ex2Sub
    pop  eax
    INVOKE ExitProcess, 0
main ENDP

Ex2Sub PROC
    pop  eax
    ret
Ex2Sub ENDP
```

`CALL`은 반환 주소를 스택에 넣는다. `Ex2Sub`의 `POP EAX`가 그 반환 주소를 꺼내므로, 이어지는 `RET`은 원래 반환 주소가 아니라 `20`을 주소로 사용하게 된다.

**정답: d. 11행에서 잘못된 주소로 반환하려 하여 런타임 오류가 발생한다.**

## 17. 코드 실행 결과

```asm
main PROC
    mov eax, 30
    push eax
    push 40
    call Ex3Sub
    INVOKE ExitProcess, 0
main ENDP

Ex3Sub PROC
    pusha
    mov eax, 80
    popa
    ret
Ex3Sub ENDP
```

`PUSHA`는 일반 목적 레지스터를 저장하고, `POPA`는 이를 복원한다. 따라서 `EAX`는 프로시저 진입 전 값인 `30`으로 돌아온다.

**정답: c. 6행에서 `EAX = 30`이다.**

## 18. 코드 실행 결과

```asm
main PROC
    mov eax, 40
    push OFFSET Here
    jmp Ex4Sub

Here:
    mov eax, 30
    INVOKE ExitProcess, 0
main ENDP

Ex4Sub PROC
    ret
Ex4Sub ENDP
```

`JMP`는 반환 주소를 자동으로 저장하지 않지만, `OFFSET Here`를 직접 스택에 넣었다. `RET`이 그 주소를 꺼내 `Here`로 이동한다.

**정답: c. 6행에서 `EAX = 30`이다.**

## 19. 코드 실행 결과

```asm
main PROC
    mov edx, 0
    mov eax, 40
    push eax
    call Ex5Sub
    INVOKE ExitProcess, 0
main ENDP

Ex5Sub PROC
    pop  eax
    pop  edx
    push eax
    ret
Ex5Sub ENDP
```

- 첫 번째 `POP EAX`는 반환 주소를 꺼낸다.
- 두 번째 `POP EDX`는 호출 전에 스택에 넣은 `40`을 꺼낸다.
- 반환 주소를 다시 스택에 넣으므로 `RET`은 정상적으로 복귀한다.

**정답: a. 6행에서 `EDX = 40`이다.**

## 20. 배열에 기록되는 값

초기 배열:

```asm
array DWORD 4 DUP(0)
```

프로그램은 각 프로시저에서 EAX에 10을 더한 후 현재 인덱스 위치에 저장한다. 각 단계에서 ESI가 4씩 증가한다.

| 저장 위치 | 저장 시점 | 값 |
|---:|---|---:|
| `array[0]` | `proc_3` | 10 |
| `array[1]` | `proc_2` | 20 |
| `array[2]` | `proc_1` | 30 |
| `array[3]` | `main` | 40 |

**최종 배열:**

```text
[10, 20, 30, 40]
```


### 2. 반환 주소를 3바이트 뒤로 이동

`RET` 직전에 스택 맨 위의 반환 주소를 3 증가시킨다.

```asm
add DWORD PTR [esp], 3
ret
```

### 3. 지역 변수용 DWORD 공간 2개 예약 및 값 저장

```asm
sub esp, 8                    ; DWORD 두 개, 총 8바이트 예약
mov DWORD PTR [esp], 1000h
mov DWORD PTR [esp+4], 2000h

; 프로시저 종료 전 지역 변수 공간 해제
add esp, 8
ret
```

---

### 4. DWORD 배열의 원소를 바로 앞 위치로 복사

아래 코드는 인덱스 `i`의 원소를 `i-1` 위치로 복사한다. `ESI`는 1부터 시작하고, `ECX`에는 처리할 원소 수를 넣는다.

```asm
; array DWORD ...
; ESI = 1
; ECX = LENGTHOF array - 1

L1:
    mov eax, array[esi*TYPE array]
    mov array[esi*TYPE array-TYPE array], eax
    inc esi
    loop L1
```

---

### 5. 반환 주소를 출력하고 정상 반환

반환 주소를 `EAX`로 복사해 출력한다. 스택에 있는 원래 반환 주소는 그대로 두므로 `RET`이 정상 작동한다.

```asm
ShowReturnAddress PROC
    mov eax, DWORD PTR [esp]
    call WriteHex
    ret
ShowReturnAddress ENDP
```

## 5. 지정한 범위의 난수 생성

`EBX`에 하한 $M$, `EAX`에 상한 $N$을 넣어 호출한다. 결과 범위는 $M$부터 $N-1$까지다.

```asm
BetterRandomRange PROC
    push ebx

    sub eax, ebx              ; 범위 크기 N - M
    call RandomRange          ; 0부터 N-M-1
    add eax, ebx              ; 결과에 M 더하기

    pop ebx
    ret
BetterRandomRange ENDP
```

50개의 난수를 출력하는 테스트 코드:

```asm
.data
runs DWORD 50

.code
main PROC
    call Randomize

L1:
    mov ebx, -300
    mov eax, 100
    call BetterRandomRange

    call WriteInt
    call Crlf

    dec runs
    jnz L1

    exit
main ENDP
```

## 6. 대문자 무작위 문자열 생성

## 9. `LOOP`을 사용한 재귀 프로시저

`ECX`에 재귀 호출 횟수를 전달한다. 각 호출에서 카운터를 증가시키고, `LOOP`이 0이 될 때까지 재귀 호출한다.

```asm
.data
callCount DWORD 0

.code
main PROC
    mov ecx, 5
    call RecursiveProc

    mov eax, callCount
    call WriteDec
    call Crlf

    exit
main ENDP

RecursiveProc PROC
    inc callCount
    loop RecurseAgain
    ret

RecurseAgain:
    call RecursiveProc
    ret
RecursiveProc ENDP
```

예시에서는 총 5번 호출되어 `callCount`가 5가 된다.

## 10. DWORD 배열에 피보나치 수열 생성

`ESI`에는 배열 주소, `ECX`에는 생성할 원소 수를 전달한다. 첫 항과 둘째 항은 각각 1이다.

```asm
.data
fibArray DWORD 47 DUP(?)

.code
main PROC
    mov esi, OFFSET fibArray
    mov ecx, LENGTHOF fibArray
    call Fibonacci

    exit
main ENDP

Fibonacci PROC USES ebx ecx esi
    mov DWORD PTR [esi], 1
    mov DWORD PTR [esi+4], 1

    mov eax, 1              ; Fib(1)
    mov ebx, 1              ; Fib(2)
    add esi, 8
    mov ecx, 45

L1:
    mov edx, eax
    add edx, ebx            ; 다음 항 계산

    mov [esi], edx
    mov eax, ebx
    mov ebx, edx

    add esi, 4
    loop L1

    ret
Fibonacci ENDP
```

47번째 항은 `2,971,215,073`이며 unsigned DWORD 범위 안에 들어간다.

## 11. BYTE 배열에서 K의 배수 표시

입력은 `ESI = 배열 주소`, `EBX = K`, `ECX = N`으로 전달한다. 0부터 시작하는 배열에서 `K`의 배수 위치에 1을 기록한다.

```asm
.data
multiples BYTE 50 DUP(0)

.code
main PROC
    mov esi, OFFSET multiples
    mov ebx, 2
    mov ecx, LENGTHOF multiples
    call MarkMultiples

    mov esi, OFFSET multiples
    mov ebx, 3
    mov ecx, LENGTHOF multiples
    call MarkMultiples

    exit
main ENDP

MarkMultiples PROC USES eax ebx ecx edx edi esi
    ; 반복 횟수 = (N - 1) / K
    mov eax, ecx
    dec eax
    xor edx, edx
    div ebx

    mov ecx, eax
    mov edi, ebx            ; 첫 번째 배수 인덱스 K

L1:
    mov BYTE PTR [esi+edi], 1
    add edi, ebx
    loop L1

    ret
MarkMultiples ENDP
```

`K=2`, `K=3`으로 차례로 호출하면 두 호출에서 표시한 위치가 배열에 함께 남는다.
