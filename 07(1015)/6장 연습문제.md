## 6.10.1 Short Answer

### 1. `AND` 연산 후 BX 값

```asm
mov bx, 0FFFFh
and bx, 6Bh
```

`FFFFh AND 006Bh = 006Bh`

**정답: `BX = 006Bh`**

---

### 2. `AND` 연산 후 BX 값

```asm

```

`91BAh AND 0092h = 0092h`

**정답: `BX = 0092h`**

`0649Bh OR 003Ah = 064BBh`


### 9. Carry, Zero, Sign 플래그 값

| 항목 | 명령어와 결과 | CF | ZF | SF |
|---|---|---:|---:|---:|
| a | `TEST` 결과가 `02h` | 0 | 0 | 0 |
| b | `6 - 5 = 1` | 0 | 0 | 0 |
| c | `5 - 7 = FEh` | 1 | 0 | 1 |

```asm
; a
mov al, 00001111b
test al, 00000010b
; 결과는 00000010b. TEST는 CF를 0으로 설정한다.

; b
mov al, 00000110b
cmp al, 00000101b
; 6 - 5 = 1

; c
mov al, 00000101b
cmp al, 00000111b
; 5 - 7 = FEh
```

### 10. ECX 값에 따라 분기하는 명령어

**정답: `JECXZ`**

### 11. `JA`와 `JNBE`에서 Zero 및 Carry 플래그 사용

`JA`와 `JNBE`는 같은 조건으로 분기한다.

```text
CF = 0 그리고 ZF = 0
```

즉, unsigned 비교에서 왼쪽 값이 오른쪽 값보다 클 때 분기한다.

### 12. 실행 후 EDX 값

```asm
mov edx, 1
mov eax, 7FFFh
cmp eax, 8000h
jl  L1
mov edx, 0
L1:
```

signed 비교에서 `7FFFh`는 `8000h`보다 작으므로 `JL`이 분기한다.

**정답: `EDX = 1`**

### 13. 실행 후 EDX 값

```asm

jb  L1
mov edx, 0
L1:
```

unsigned 비교에서 `7FFFh`는 `8000h`보다 작으므로 `JB`가 분기한다.

**정답: `EDX = 1`**

---

### 14. 실행 후 EDX 값

```asm
mov edx, 1
mov eax, 7FFFh
cmp eax, 0FFFF8000h
jl  L2
mov edx, 0
L2:
```

signed 비교에서 `7FFFh`는 양수 `32767`, `0FFFF8000h`는 음수 `-32768`로 해석된다. `32767 < -32768`은 거짓이므로 분기하지 않는다.

**정답: `EDX = 0`**

### 15. Target으로 분기하는가?

```asm

cmp eax, -50
jg  Target
```

signed 비교에서 `-30 > -50`이 참이다.

**정답: True**

### 16. Target으로 분기하는가?


`JA`는 unsigned 비교를 한다. `-42`의 32비트 표현은 `FFFFFFD6h`이며, unsigned 값으로 보면 `26`보다 크다.

**정답: True**

# 6.10.2 Algorithm Workbench

> 32비트 MASM 기준으로 작성했다. 7~9번은 별도 표기가 없으므로 **unsigned 정수 비교**를 가정했다. signed 비교라면 `JA/JBE` 대신 `JG/JLE` 등의 명령어를 사용하면 된다.

## 1. ASCII 숫자를 해당 숫자값으로 변환

ASCII 문자 `'0'`~`'9'`는 하위 4비트에 숫자값을 갖는다. 이미 `00h`~`09h`이면 그대로 유지된다.

```asm
and al, 0Fh
```

---

## 2. 32비트 메모리 피연산자의 패리티 계산

아래 코드는 32비트의 모든 비트를 XOR로 접어(parity folding) 최종 패리티를 `EAX`의 최하위 비트에 남긴다.

```asm
mov eax, DWORD PTR [value]

mov edx, eax
shr edx, 16
xor eax, edx

mov edx, eax
shr edx, 8
xor eax, edx

mov edx, eax
shr edx, 4
xor eax, edx

mov edx, eax
shr edx, 2
xor eax, edx

mov edx, eax
shr edx, 1
xor eax, edx

and eax, 1
```

결과:

- `EAX = 0`: 1비트의 개수가 짝수
- `EAX = 1`: 1비트의 개수가 홀수

---

## 3. SetX에는 포함되고 SetY에는 포함되지 않는 비트 구하기

비트 집합 연산은 다음과 같다.

$$\text{SetX AND NOT SetY}$$

```asm
mov eax, DWORD PTR [SetY]
not eax
and eax, DWORD PTR [SetX]
```

결과는 `EAX`에 저장된다.

---

## 4. DX가 CX보다 작거나 같을 때 분기

unsigned 비교이므로 `JBE`를 사용한다.

```asm
cmp dx, cx
jbe L1
```

---

## 5. AX가 CX보다 클 때 분기

signed 비교이므로 `JG`를 사용한다.

```asm
cmp ax, cx
jg L2
```

---

## 6. AL의 0번과 1번 비트를 지우고 결과에 따라 분기

```asm
and al, 0FCh
jz  L3
jmp L4
```

`AND 0FCh`는 AL의 하위 2비트를 0으로 만든다. 그 결과가 0이면 `L3`, 아니면 `L4`로 이동한다.

## 7. AND 조건문 구현

의사 코드:

```text
if (val1 > ecx) AND (ecx > edx)
    X = 1
else
    X = 2
```

```asm
mov eax, val1
cmp eax, ecx
jbe Else7

cmp ecx, edx
jbe Else7

mov X, 1
jmp End7

Else7:
    mov X, 2

End7:
```

첫 번째 조건이 거짓이면 두 번째 조건은 검사하지 않아 short-circuit 평가를 한다.

---

## 8. OR 조건문 구현

의사 코드:

```text
if (ebx > ecx) OR (ebx > val1)
    X = 1
else
    X = 2
```

```asm
cmp ebx, ecx
ja  True8

cmp ebx, val1
ja  True8

mov X, 2
jmp End8

True8:
    mov X, 1

End8:
```

첫 번째 조건이 참이면 두 번째 조건은 검사하지 않는다.

---

## 9. AND와 OR가 포함된 조건문 구현

의사 코드:

```text
if (ebx > ecx AND ebx > edx) OR (edx > eax)
    X = 1
else
    X = 2
```

```asm
cmp ebx, ecx
jbe CheckOr9

cmp ebx, edx
ja  True9

CheckOr9:
    cmp edx, eax
    ja  True9

    mov X, 2
    jmp End9

True9:
    mov X, 1

End9:
```

두 비교가 모두 참이면 첫 번째 AND 조건이 참이므로 OR의 두 번째 조건은 검사하지 않는다.

---

## 10. WHILE 및 조건문 구현

의사 코드:

```text
while N > 0
    if N != 3 AND (N < A OR N > B)
        N = N - 2
    else
        N = N - 1
```

A, B, N은 signed 32비트 정수이므로 signed 조건 분기를 사용한다.

```asm
WhileLoop:
    mov eax, N
    cmp eax, 0
    jle EndWhile

    cmp eax, 3
    je  SubtractOne

    cmp eax, A
    jl  SubtractTwo

    cmp eax, B
    jg  SubtractTwo

SubtractOne:
    dec N
    jmp WhileLoop

SubtractTwo:
    sub N, 2
    jmp WhileLoop

EndWhile:
```

`N < A`가 참이면 `N > B`는 확인하지 않고 `N = N - 2`를 수행한다.

# 6.11 Programming Exercises

> 기준: **32비트 MASM + Irvine32**. 각 문제는 핵심 프로시저와 호출 예제를 중심으로 작성했다.

## 1. 배열에 범위 내 난수 채우기

입력 레지스터: `ESI` = 배열 주소, `ECX` = 원소 개수 $N$, `EBX` = 최솟값 $j$, `EDX` = 최댓값 $k`.  
각 값은 $j \leq x \leq k$ 범위에서 생성한다. `PUSHAD`와 `POPAD`로 레지스터를 보존한다.

```asm
.data
localArray DWORD 20 DUP(?)
fillPtr    DWORD ?
fillCount  DWORD ?
fillMin    DWORD ?
fillMax    DWORD ?

.code
FillArray PROC
    push ebp
    mov ebp, esp
    sub esp, 16

    mov [ebp-4],  esi        ; 배열 주소
    mov [ebp-8],  ecx        ; 원소 개수
    mov [ebp-12], ebx        ; 최솟값 j
    mov [ebp-16], edx        ; 최댓값 k

    pushad

    mov esi, [ebp-4]
    mov ecx, [ebp-8]
    jecxz FillDone

FillLoop:
    ; RandomRange는 0부터 EAX-1까지 난수를 반환
    mov eax, [ebp-16]
    sub eax, [ebp-12]
    inc eax                  ; 범위 크기 k-j+1

    push ecx
    push esi
    call RandomRange
    pop esi
    pop ecx

    add eax, [ebp-12]        ; 난수 범위를 j부터 시작하도록 이동
    mov [esi], eax
    add esi, TYPE DWORD

    loop FillLoop

FillDone:
    popad
    mov esp, ebp
    pop ebp
    ret
FillArray ENDP
```

호출 예시:

```asm
.data
array1 DWORD 20 DUP(?)
array2 DWORD 20 DUP(?)

.code
call Randomize

mov esi, OFFSET array1
mov ecx, LENGTHOF array1
mov ebx, 10
mov edx, 50
call FillArray              ; 10~50 범위

mov esi, OFFSET array2
mov ecx, LENGTHOF array2
mov ebx, -20
mov edx, 20
call FillArray              ; -20~20 범위
```

## 2. 지정 범위에 포함되는 배열 값의 합 구하기

입력 레지스터: `ESI` = signed DWORD 배열 주소, `ECX` = 원소 수, `EBX` = 하한 $j$, `EDX` = 상한 $k$.  
$ j \leq 값 \leq k $인 원소만 더하고, 결과를 `EAX`로 반환한다. `EAX` 외의 레지스터는 보존한다.

```asm
CalcRangeSum PROC USES ebx ecx edx esi edi ebp
    mov edi, 0              ; 합계
    jecxz SumDone

SumLoop:
    mov ebp, [esi]

    cmp ebp, ebx
    jl  SkipValue           ; 값 < j

    cmp ebp, edx
    jg  SkipValue           ; 값 > k

    add edi, ebp

SkipValue:
    add esi, TYPE DWORD
    loop SumLoop

SumDone:
    mov eax, edi
    ret
CalcRangeSum ENDP
```

호출 예시:

```asm
.data
values DWORD -5, 3, 8, 12, 20
sum1   SDWORD ?
sum2   SDWORD ?

.code
mov esi, OFFSET values
mov ecx, LENGTHOF values
mov ebx, 3
mov edx, 12
call CalcRangeSum
mov sum1, eax

mov esi, OFFSET values
mov ecx, LENGTHOF values
mov ebx, -5
mov edx, 8
call CalcRangeSum
mov sum2, eax
```

## 3. 점수를 문자 등급으로 변환

`EAX`에 점수(0~100)를 전달하고, `AL`에 문자 등급을 반환한다. `EAX`를 제외한 레지스터는 보존한다.

```asm
CalcGrade PROC USES ebx ecx edx esi edi ebp
    cmp eax, 90
    jae GradeA

    cmp eax, 80
    jae GradeB

    cmp eax, 70
    jae GradeC

    cmp eax, 60
    jae GradeD

    mov al, 'F'
    ret

GradeA:
    mov al, 'A'
    ret

GradeB:
    mov al, 'B'
    ret

GradeC:
    mov al, 'C'
    ret

GradeD:
    mov al, 'D'
    ret
CalcGrade ENDP
```

50~100 범위 난수를 10번 생성해 점수와 등급을 출력하는 예:

```asm
.data
scoreVal DWORD ?
gradeVal BYTE ?
runs     DWORD 10

.code
call Randomize

GradeTestLoop:
    mov eax, 51
    call RandomRange         ; 0~50
    add eax, 50              ; 50~100
    mov scoreVal, eax

    call CalcGrade
    mov gradeVal, al

    mov eax, scoreVal
    call WriteDec
    mov al, ' '
    call WriteChar
    mov al, gradeVal
    call WriteChar
    call Crlf

    dec runs
    jnz GradeTestLoop
```

## 4. College Registration

이 예제는 학점 평균이 **200 이상**이고 신청 학점이 **1~30**이면 등록할 수 있다고 가정한다.

```asm
.data
promptAverage BYTE "학점 평균 입력(0~400): ", 0
promptCredits BYTE "신청 학점 입력(1~30): ", 0
errorMessage  BYTE "오류: 신청 학점은 1~30이어야 합니다.", 0
canRegister   BYTE "학생은 등록할 수 있습니다.", 0
cannotRegister BYTE "학생은 등록할 수 없습니다.", 0

gradeAverage SDWORD ?
credits      SDWORD ?

.code
main PROC
    mov edx, OFFSET promptAverage
    call WriteString
    call ReadInt
    mov gradeAverage, eax

    mov edx, OFFSET promptCredits
    call WriteString
    call ReadInt
    mov credits, eax

    cmp eax, 1
    jl  InvalidCredits
    cmp eax, 30
    jg  InvalidCredits

    mov eax, gradeAverage
    cmp eax, 200
    jl  CannotEnroll

    mov edx, OFFSET canRegister
    call WriteString
    jmp RegistrationDone

InvalidCredits:
    mov edx, OFFSET errorMessage
    call WriteString
    jmp RegistrationDone

CannotEnroll:
    mov edx, OFFSET cannotRegister
    call WriteString

RegistrationDone:
    call Crlf
    exit
main ENDP
```

## 5~6. Boolean Calculator

선택 메뉴를 출력하고, 연산 이름을 테이블에서 찾아 표시한 뒤 해당 프로시저를 호출한다. 각 연산은 16진수 입력을 받고 결과를 16진수로 출력한다.

```asm
INCLUDE Irvine32.inc

.data
menuText BYTE \
"1. x AND y", 13, 10, \
"2. x OR y", 13, 10, \
"3. NOT x", 13, 10, \
"4. x XOR y", 13, 10, \
"5. 종료", 13, 10, \
"선택: ", 0

promptX BYTE "x 입력(16진수): ", 0
promptY BYTE "y 입력(16진수): ", 0
operationLabel BYTE "연산: ", 0
resultLabel BYTE "결과: ", 0
invalidChoice BYTE "잘못된 선택입니다.", 0

nameAND BYTE "x AND y", 0
nameOR  BYTE "x OR y", 0
nameNOT BYTE "NOT x", 0
nameXOR BYTE "x XOR y", 0

opNames DWORD OFFSET nameAND, OFFSET nameOR, OFFSET nameNOT, OFFSET nameXOR
opTable DWORD OFFSET AND_op, OFFSET OR_op, OFFSET NOT_op, OFFSET XOR_op

choice   DWORD ?
operandX DWORD ?
operandY DWORD ?

.code
main PROC
MenuLoop:
    mov edx, OFFSET menuText
    call WriteString
    call ReadInt

    cmp eax, 5
    je  ExitProgram
    cmp eax, 1
    jl  Invalid
    cmp eax, 4
    jg  Invalid

    mov choice, eax

    mov edx, OFFSET operationLabel
    call WriteString

    mov eax, choice
    dec eax
    mov esi, OFFSET opNames
    mov edx, [esi+eax*TYPE opNames]
    call WriteString
    call Crlf

    mov eax, choice
    dec eax
    mov esi, OFFSET opTable
    call DWORD PTR [esi+eax*TYPE opTable]

    call Crlf
    jmp MenuLoop

Invalid:
    mov edx, OFFSET invalidChoice
    call WriteString
    call Crlf
    jmp MenuLoop

ExitProgram:
    exit
main ENDP

AND_op PROC
    mov edx, OFFSET promptX
    call WriteString
    call ReadHex
    mov operandX, eax

    mov edx, OFFSET promptY
    call WriteString
    call ReadHex
    mov operandY, eax

    mov eax, operandX
    and eax, operandY
    jmp ShowBooleanResult
AND_op ENDP

OR_op PROC
    mov edx, OFFSET promptX
    call WriteString
    call ReadHex
    mov operandX, eax

    mov edx, OFFSET promptY
    call WriteString
    call ReadHex
    mov operandY, eax

    mov eax, operandX
    or  eax, operandY
    jmp ShowBooleanResult
OR_op ENDP

NOT_op PROC
    mov edx, OFFSET promptX
    call WriteString
    call ReadHex

    not eax
    jmp ShowBooleanResult
NOT_op ENDP

XOR_op PROC
    mov edx, OFFSET promptX
    call WriteString
    call ReadHex
    mov operandX, eax

    mov edx, OFFSET promptY
    call WriteString
    call ReadHex
    mov operandY, eax

    mov eax, operandX
    xor eax, operandY
    jmp ShowBooleanResult
XOR_op ENDP

ShowBooleanResult:
    mov edx, OFFSET resultLabel
    call WriteString
    call WriteHex
    call Crlf
    ret

END main
```

## 7. 확률에 따라 색상을 선택해 문장 출력

난수 0~2는 흰색, 3은 파란색, 4~9는 초록색으로 출력한다.

```asm
.data
lineText BYTE "Assembly language", 0
runs     DWORD 20

.code
main PROC
    call Randomize

ColorLoop:
    mov eax, 10
    call RandomRange         ; 0~9

    cmp eax, 3
    jb  UseWhite
    je  UseBlue

    mov eax, green
    jmp SetColor

UseWhite:
    mov eax, white
    jmp SetColor

UseBlue:
    mov eax, blue

SetColor:
    call SetTextColor

    mov edx, OFFSET lineText
    call WriteString
    call Crlf

    dec runs
    jnz ColorLoop

    mov eax, lightGray
    call SetTextColor
    exit
main ENDP
```

## 8. 반복 키를 이용한 XOR 암호화와 복호화

메시지 각 바이트와 반복되는 키 바이트를 XOR한다. XOR은 같은 키를 한 번 더 적용하면 원래 메시지로 복구된다.

```asm
.data
plainText BYTE "This is a plain text message", 0
secretKey BYTE "ABXmv#7", 0
keyLength = LENGTHOF secretKey - 1
textLength = LENGTHOF plainText - 1

.code
XorCrypt PROC USES eax ebx ecx edx esi edi
    xor edx, edx             ; 키 인덱스 0부터 시작

CryptLoop:
    mov al, [esi]
    xor al, [edi+edx]
    mov [esi], al

    inc esi
    inc edx
    cmp edx, ebx
    jb  KeyIndexReady
    xor edx, edx

KeyIndexReady:
    loop CryptLoop
    ret
XorCrypt ENDP

main PROC
    mov esi, OFFSET plainText
    mov edi, OFFSET secretKey
    mov ebx, keyLength
    mov ecx, textLength
    call XorCrypt            ; 암호화

    ; 암호문 바이트를 메모리 창 또는 DumpMem으로 확인 가능
    mov esi, OFFSET plainText
    mov ebx, 1
    mov ecx, textLength
    call DumpMem

    mov esi, OFFSET plainText
    mov edi, OFFSET secretKey
    mov ebx, keyLength
    mov ecx, textLength
    call XorCrypt            ; 복호화

    mov edx, OFFSET plainText
    call WriteString
    call Crlf
    exit
main ENDP
```

## 9. 5자리 PIN 검증

PIN은 숫자 문자로 저장한다. 예를 들어 `"52413"`의 각 바이트는 ASCII 문자이다. 프로시저는 유효 범위를 벗어난 자릿수(1~5)를 `EAX`로 반환하며, 모두 유효하면 0을 반환한다.

```asm
.data
minRange BYTE 5, 2, 4, 1, 3
maxRange BYTE 9, 5, 8, 4, 6

pinValid    BYTE "52413"
pinBadFirst BYTE "43534"
pinBadLast  BYTE "64537"

result1 DWORD ?
result2 DWORD ?
result3 DWORD ?

.code
Validate_PIN PROC USES ebx ecx edx esi edi ebp
    mov ecx, 5
    xor edi, edi             ; 배열 인덱스 0부터

PinLoop:
    movzx eax, BYTE PTR [esi+edi]
    sub eax, '0'             ; ASCII 숫자를 정수 0~9로 변환

    movzx ebx, BYTE PTR minRange[edi]
    cmp eax, ebx
    jb  InvalidDigit

    movzx ebx, BYTE PTR maxRange[edi]
    cmp eax, ebx
    ja  InvalidDigit

    inc edi
    loop PinLoop

    xor eax, eax             ; 유효한 PIN
    ret

InvalidDigit:
    lea eax, [edi+1]         ; 자릿수는 1부터 반환
    ret
Validate_PIN ENDP

main PROC
    mov esi, OFFSET pinValid
    call Validate_PIN
    mov result1, eax         ; 0

    mov esi, OFFSET pinBadFirst
    call Validate_PIN
    mov result2, eax         ; 1

    mov esi, OFFSET pinBadLast
    call Validate_PIN
    mov result3, eax         ; 5

    exit
main ENDP
```

> 제시된 표의 마지막 자릿수 허용 범위가 3~6이라면 `"64535"`는 유효하다. 마지막 자릿수 오류를 테스트하기 위해 `"64537"`을 사용했다.

## 10. 바이트 배열 전체의 패리티 검사

모든 비트의 개수가 짝수이면 `EAX = 1`, 홀수이면 `EAX = 0`을 반환한다. `XOR`로 각 바이트를 누적한 뒤 `TEST`로 최종 패리티 플래그를 설정한다.

```asm
.data
evenBytes BYTE 03h, 00h, 00h, 00h, 00h, 00h, 00h, 00h, 00h, 00h
oddBytes  BYTE 01h, 00h, 00h, 00h, 00h, 00h, 00h, 00h, 00h, 00h

evenResult DWORD ?
oddResult  DWORD ?

.code
CheckParity PROC USES ebx ecx esi
    xor ebx, ebx

ParityLoop:
    xor bl, BYTE PTR [esi]
    inc esi
    loop ParityLoop

    test bl, bl              ; PF는 BL의 1 비트 개수가 짝수이면 1
    setp al                  ; 짝수 패리티이면 AL=1
    movzx eax, al
    ret
CheckParity ENDP

main PROC
    mov esi, OFFSET evenBytes
    mov ecx, LENGTHOF evenBytes
    call CheckParity
    mov evenResult, eax      ; 1

    mov esi, OFFSET oddBytes
    mov ecx, LENGTHOF oddBytes
    call CheckParity
    mov oddResult, eax       ; 0

    exit
main ENDP
```
